# Logo Directory

## Upload Your Logo

Place your station logo here as `etel-logo.png`

### Requirements:
- **Filename**: `etel-logo.png`
- **Format**: PNG (with transparent background recommended)
- **Size**: 512x512 pixels (recommended)
- **Max file size**: 500KB
- **Aspect ratio**: 1:1 (square)

### Usage:
The logo appears in:
- Driver interface header
- Controller panel header
- Admin panel sidebar
- Login screens
- Footer

### Quick Tips:
1. Use a square logo for best results
2. Transparent background works best
3. High resolution for retina displays
4. Keep file size under 500KB for fast loading

### Example:
```
assets/img/etel-logo.png  ← Your logo goes here
```

If you don't have a logo yet, you can use a placeholder or create one using:
- Canva (https://canva.com)
- Adobe Express (https://express.adobe.com)
- GIMP (free, open-source)
- Photoshop

### Default Placeholder:
Until you upload your logo, the system will show a broken image icon. Upload your logo to fix this.
