Configure Your API Key
EtelAudit Pro uses Claude AI to analyze your projects. You need a free Anthropic API key to activate it. Setup takes 2 minutes.
1
Visit aistudio.google.com/app/apikey and sign in with your Google account (completely free, no credit card).
2
Open EtelGebeya/audit/proxy.php in cPanel File Manager → right-click → Edit.
3
Find this line and replace the placeholder with your Gemini key:
define('GEMINI_API_KEY', 'PASTE_YOUR_GEMINI_KEY_HERE');
4
Save the file, then tap Test Connection below. Analysis is 100% free.
