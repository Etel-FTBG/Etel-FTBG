🔐 Roles & Permissions

Staff signed in via "Sign in with EtelID" get access based on the role assigned to them in Etel Group's Employees panel. Define what each role name is allowed to do here. "Owner", "Admin", and "Manager" default to unrestricted access; any new role name starts with view-only access to Orders and Rides until you configure it below.

📊 Platform Economics

Real 5% commission revenue from completed rides, weighed against real cost assumptions you enter below. The revenue side is always live data — the cost side is only as accurate as what you fill in. Gated by platform_economics.view/.manage.

🤝 Equb (Rotating Savings)

Real money moves automatically between participants' wallets. Only you can create or start a group — permitted users can join what you've set up, but never create their own. Grant a phone number below before anyone can join at all. A scheduled cron job processes rounds automatically once configured; use "Process Now" here to manually trigger one in the meantime or to recover an at-risk group.

☠️ Danger Zone — Full System Reset

Permanently deletes real orders, rides, ratings, driver/service-giver profiles, and user accounts across the whole system. This cannot be undone except by restoring the backup file this tool generates for you. Gated by the system.reset capability — not included in a normal Owner grant, must be added explicitly in the Roles panel.
