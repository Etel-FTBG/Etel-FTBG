⚠ Two real bugs found and fixed this session

  • customer.html had NO PWA manifest link at all - "Add to Home Screen" fell back to whatever the browser had cached from elsewhere in the origin, which is why it showed Service Giver's icon. Fixed with the same static tag pattern driver/ride already used correctly.
  • login.html's role-detection had explicit branches for driver/ride/courier/service/admin but none for customer - added isCustomer for consistency (customer.html's own fix above is what mattered in practice).
  • If Driver still shows the wrong icon on a specific phone: that's a stale, already-installed home-screen shortcut, not a code bug - the manifest link itself is already correct.
